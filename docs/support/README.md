# 支持作者

Mediary Scout 是我一个人业余做的开源项目，不收费，也不做托管服务。服务器、测试用的网盘会员和 AI 调用都是自掏腰包。

## 产品内不做打赏入口

这个项目**刻意不在产品里放任何打赏/赞助入口**——不弹窗、不在页脚挂「请作者喝杯咖啡」、不用任何功能换赞助。理由很直接：自部署工具的用户里不少是搭给家人朋友合用的，界面里出现募捐按钮会让人怀疑「这功能是不是要付费」，而所有功能本来就对所有人一样。

此前的收款码与「喝咖啡」入口已从产品和仓库中移除。

## 如果你确实想支持

不需要花钱，这几样对项目的帮助比捐款大：

- **提 Issue**：缺陷、部署卡住、文档看不懂，都是最直接的帮助。
- **帮你所在的场景做适配**：新的网盘、新的部署环境、新的使用方式。
- **把文档改得更好**：你觉得绕的地方，别人也会觉得绕。

## 鸣谢

This is a free, open-source side project with no hosted service and no paid tier. It deliberately ships **no donation or sponsorship prompt anywhere in the product** — no modal, no footer link, no feature gated behind a tip. If it saves you time and you'd like to help, an Issue report or a docs fix is worth more than money.
