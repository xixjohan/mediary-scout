# v2026.11.13.2

- 新增 播放器布局状态机（`pending → fitted / fallback`）：视频元数据缺失或加载失败时强制 `contain` 确定性兜底，控制条贴容器底部成为不变量
- 新增 竖屏（< 0.8）与超宽（> 2.4）片源专用适配策略：竖屏按容器高度等比居中并限制最大宽度、禁用 `cover` 硬裁，超宽否决裁切并保留完整画面
- 新增 投送模式账号级记忆：手动切换后写入 `account_settings`，刷新 / 重开播放器保持偏好，并提供「恢复默认」入口交回库 / 绑定配置
- 新增 播放器内投送决策原因常驻提示，直接展示 `deliverySource` / `deliveryReason`，不再依赖 hover
- 改进 布局与适配策略拆为纯函数并补充 15 例单测，覆盖四类片源比例、两种窗口尺寸与脏数据白名单校验
- 改进 验收脚本支持通过环境变量切换目标实例、注入生产会话，并在生产环境采用扫描只读模式
- 修复 换流瞬间 `data-viewport-fit` 诊断标记残留上一片源状态的问题
- 修复 Runbook 文档中写入真实私网主机地址导致的 `gate:security` (SEC-007) 违规，统一改为占位符
