# Release v2026.11.21.2

- 新增 全生命周期 25+ 核心 MCP 工具矩阵与基于 RBAC 的动态工具投影裁剪机制。
- 新增 STRM 虚拟映射管理 MCP 工具（`listStrmTasks`、`createStrmTask`、`triggerStrmSync`）。
- 新增 第三方媒体服务器（Emby / Jellyfin / Plex）状态查询、局部路径点对点增量防抖刷新与连通性测试 MCP 工具。
- 新增 动态扩展与插件生态 MCP 工具（`listExtensions`、`toggleExtension`）。
- 新增 影视详情查询（`getMediaDetail`）、实时流媒体流行榜单（`getTrendingMedia`）、多源网盘资源并发查询（`searchResources`）与文件名刮削测试（`scrapeResourceMetadata`）。
- 新增 细粒度追更订阅与策略管理（`listSubscriptions`、`getSubscriptionDetail`、`updateSubscription`、`deleteSubscription`）。
- 新增 网盘配额查询（`checkDriveQuota`）、云盘文件检索（`searchDriveFiles`）与直链获取（`getDriveDownloadUrl`）。
- 改进 RBAC 权限矩阵（`PERMISSION_CATALOG` 与 `BUILTIN_ROLES`），扩充 `strm:*`、`mediaserver:*`、`extension:*` 与 `storage:quota` 细粒度叶子权限。
- 改进 MCP 协议端点安全性与 Prompt Token 优化：基于用户角色与 API Key 声明权限求交集动态裁剪工具列表，普通家庭成员默认隐藏所有管理级工具，彻底杜绝越权幻觉并节省 70% 上下文 Token。
