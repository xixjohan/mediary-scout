# Release v2026.11.21.3

- 新增 API Key 与应用授权管理 (V2) 支持对已有凭据授权就地编辑功能（修改 Key 名称、细粒度权限勾选树、有效期调整与 REST API / MCP 双通道开关），保持底层原始密钥与加盐哈希不变，客户端免重新配置。
- 新增 `ApiKeyMutationStrategy.calculateDiff` 权限差异计算与高危权限审计变异检测，实时感知权限增删与风险跃迁。
- 新增 `ApiKeyV2Store.updateKey` 领域更新仓储方法，具备状态机不可逆终态防御（已吊销禁止编辑）、子集不变性委托边界防御（防越权提权）、协议通道有效性校验与前缀缓存精准驱逐。
- 改进 API Key 管理交互体验：支持独立 `EditApiKeyModal` 就地修改凭据属性与即时局部刷新；解耦重构 `RevealedApiKeyModal` 一次性明文与客户端接入代码片段生成弹窗。
- 改进 API Key 复制体验：深度适配局域网非安全上下文（HTTP / NAS 部署）环境，提供标准 Clipboard API 与 `document.execCommand` 隐藏输入框三级降级，保障复制反馈即时可信。
