# Release v2026.11.22

- 新增 网盘临时目录原子清理 MCP 工具 (`cleanStagingDirectories`)：支持定向扫描与安全清理特定影视作品下的 safe staging 临时目录，解耦全量整理链路。
- 新增 季目录多版本去重软归档 MCP 工具 (`dedupeSeasonVersions`)：支持针对指定季度或全剧执行多版本视频质量对齐与软归档，避免冗余版本堆积。
- 改进 网盘影视整理执行架构 (`executeOrganizeMedia`)：新增 `asyncExecution` 异步执行模式并默认启用，在 50ms 内快速返回 `taskId` 彻底解决外部客户端（如 AITool）的 30 秒硬超时限制，后台异步驱动状态机与 SQLite 持久化；同时补齐 `directoryId` 路由参数。
- 修复 115 网盘文件与目录误判缺陷：在 `drive-file-manager.ts` 与 `landed-media.ts` 中重构判定逻辑，综合文件扩展名、提取码、sha1 与图标判断，彻底修复部分 115 视频文件被误判为 `isFolder: true, sizeBytes: 0` 的问题。
- 改进 Staging 临时目录安全回收规则：实现 `isSafeStagingRemnant` 放宽删除白名单，允许在无核心视频文件时安全清理 `.nfo`、`.txt`、海报图片等元数据残留，彻底杜绝 staging 临时目录泄漏残留。
